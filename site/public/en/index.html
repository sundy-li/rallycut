01　/　Review

Review each point,
not every minute.

Where the machine cuts wrong, add rallies by hand or adjust start and end times. Both versions can be kept, and you decide which to use at export.

Choose “Manual rallies override analysis” to use your version. Overlapping analysis rallies are skipped whole, and the project timeline is not changed.

Download installers on GitHub ↗

Source code and installers are public. Download without an invitation or GitHub sign-in. Choose the installer for your system under the release's Assets; the source code ZIP is not an installer.

Installation notes and privacy
  • The full Windows installer already includes Python, FFmpeg and the analysis dependencies, so you don't install them; the window still needs WebView2.
  • If the model is missing on first use, about 6 MB is downloaded after you confirm; on macOS the app prepares a private environment after you confirm. After setup, all video processing happens on your computer.
  • On Windows, later launches in the same environment skip the setup page; upgrades or changed files trigger a new check.
  • Installers are not yet signed by a registered publisher or notarized by Apple, so the system may block them. If unsure, contact the maintainer rather than turning off system protection.
  • Automatic results need human review. Intel Macs and Windows still need more testing on real machines.
  • The app interface is currently in Chinese; the English guide maps each button.
Model and privacy

Installers don't bundle model weights; the upstream redistribution and commercial-use terms are still being confirmed. The app doesn't upload match videos or send telemetry. The site host and the first-run download sources may keep their own access logs.
