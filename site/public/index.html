安装前须知与隐私说明
  • Windows 完整安装器已含 Python、FFmpeg 和分析依赖，无需自行安装；窗口仍需要 WebView2。
  • 首次缺模型时，确认后下载约 6 MB；macOS 确认后自动准备私有环境。准备完成后视频处理都在本机进行。
  • Windows 同一环境后续启动跳过准备页，不再重复运行依赖探测；升级或内容变化时会重新检查。
  • 安装包尚未完成正式发布者签名／Apple 公证，系统可能拦截；拿不准时请联系维护者，不要关闭系统安全保护。
  • 自动结果需要人工复核；Intel Mac 和 Windows 仍需进一步实机验证。
模型与隐私说明

安装包不捆绑模型权重，上游权重的独立分发／商用条款仍在确认中。应用不会自动上传比赛视频或发送遥测；网站托管和首次下载依赖的平台可能保留各自的访问日志。
