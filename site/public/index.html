从原片到集锦，只需三步

找到回合，
留下精彩。

先用一小段比赛试试。
不必一开始就处理整场素材。

  1. 01 / 导入

    把比赛放进来。

    导入本地视频，开始分析。候选回合会逐步出现在列表与时间轴中。

  2. 02 / 复核

    挑出值得留的回合。

    回看球轨迹，修正起止点、补上漏掉的回合，或删掉误识别。改错了可以撤销、重做。

  3. 03 / 导出

    让好球变成集锦。

    勾选回合，在导出栏开启“球轨迹”和“回合编号”，导出带原声的 MP4。一个回合、一段集锦，都可以。

前往 GitHub 下载安装包 ↗

下载需要 GitHub 仓库权限。 请先接受维护者邀请，再登录被邀请的账号；没有权限时，GitHub 可能显示 404。当前不支持匿名下载。

第一次使用前，请留意

  • 需自行安装 Python 3.10+（推荐 3.12）、FFmpeg 和 FFprobe；Windows 还需要 WebView2。
  • 首次启动需联网准备运行环境。准备完成后，视频分析和导出都在本机进行。
  • 安装包尚未完成正式发布者签名／Apple 公证，系统可能拦截；拿不准时请联系维护者，不要关闭系统安全保护。
  • 自动结果需要人工复核；Intel Mac 和 Windows 仍需进一步实机验证。
模型与隐私说明

安装包不捆绑模型权重，上游权重的独立分发／商用条款仍在确认中。应用不会自动上传比赛视频或发送遥测；网站托管和首次下载依赖的平台可能保留各自的访问日志。
