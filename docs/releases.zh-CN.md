# 本版更新

## v0.1.0-alpha.2 · 种子测试

**这次的重点：从“找到回合”到“把轨迹和回合编号带进成片”。**

### 你可以直接体验

- **带轨迹的集锦**：导出时勾选“球轨迹”，球的橙色拖尾与圆圈会保留在 MP4 中；也可以叠加左上角的回合编号。
- **更顺手的编辑**：双击回合时间修改边界，右键处理回合，支持撤销／重做；独立进度条可以直接拖动定位。
- **设置与快捷键**：片段前后保留时间、导出编码和播放步长集中在设置中，快捷键有独立面板。
- **保留人工修改**：重新分析会保留人工添加与修正的回合；有重叠时可选择导出优先级。
- **回合识别改进**：更新不同机位下的发球、回合边界与移动镜头处理；减少部分场外轨迹的显示干扰。识别仍可能出错，需要回放复核。
- **实际视频演示**：[观看樊振东比赛片段的短集锦](https://rallycut-byc.pages.dev/#demo)，带真实保存轨迹与回合编号。

### 下载与升级

[打开本版 GitHub Release](https://github.com/sundy-li/rallycut/releases/tag/v0.1.0-alpha.2)。安装包只在构建成功后出现，并附对应 SHA-256 校验清单。下载需要已获授权的 GitHub 账号。

退出旧应用，备份项目后再替换应用。保留原视频的名称与路径，先用短素材检查再继续原项目。旧版下载入口将由本版取代，不要混用不同版本写入同一项目。

### 试用前须知

- macOS 优先，通用包目标为 Apple Silicon／Intel；主要实机验证来自 Apple Silicon。Windows amd64 为实验性支持，构建成功不代表真机验收。
- 需自行安装 Python 3.10+（推荐 3.12）、FFmpeg／FFprobe；Windows 还需要 WebView2。首次启动需联网准备运行环境与模型。
- 安装包没有正式发布者签名／Apple 公证，系统可能拦截；确认来源后按提示处理，不要关闭系统安全保护。
- 视频在本机处理，自动结果不是最终剪辑或裁判结论。
- 回合编号需要系统中文字体；缺少字体时应用会提示，可先关闭编号导出。
- 项目不含原片，暂不支持素材重定位。撤销历史不是备份，切换项目、素材或完成分析后会清空。
- 模型权重不随安装包分发，其独立再分发／商用条款尚未确认。
