# Windows 安装与验证说明

当前统一版本：**v0.1.0-alpha.3**。[打开私有下载页](https://github.com/sundy-li/rallycut/releases/tag/v0.1.0-alpha.3)。需要 `sundy-li/rallycut` 仓库权限；未授权账号可能看到 404。历史 Windows 测试版与旧 macOS 下载已撤下，网站默认入口统一指向本版。

这是 Windows x64 包，不是原生 ARM64；Windows 11 ARM 将通过模拟运行。通用用户说明见[安装指南](getting-started.zh-CN.md)，功能与限制见[本版更新](releases.zh-CN.md)。

## 下载与安装

- **首选完整安装器**：`RallyCut-0.1.0-alpha.3-windows-amd64-setup.exe`。中文、按当前用户安装；安装时已经展开私有 Python、NumPy／OpenCV／PyTorch、FFmpeg／FFprobe 与 app-local Visual C++ 运行库，不在用户电脑执行 pip，不改系统 Python 或全局 PATH。
- **免安装备用**：`RallyCut-0.1.0-alpha.3-windows-amd64.exe` 与 `RallyCut-runtime-windows-amd64.zip` 放在同目录。首次需校验并展开 ZIP；不要把仅 EXE 的拷贝当完整离线包。
- **校验**：`SHA256SUMS-windows.txt` 覆盖 Windows 交付文件，`runtime-bundle.json` 固定运行环境的版本、大小与哈希。
- 模型权重不打包。缺少时明确点击后才单独下载约 6 MB 模型，并按固定哈希校验；已有合格模型可复用。
- 缺 WebView2 时先出现中文原生确认提示，取消则退出；系统已具备时不重复提示。

安装包未正式签名。先确认来源和校验值，拿不准时联系维护者，不要关闭系统整体安全保护。升级前退出旧窗口、备份项目再安装，不需要卸载或删除用户数据。

## 本版 Windows 改进

- 原生 Unicode 多选保留中文、空格、符号、emoji 与 UNC 前缀，不再经 PowerShell 文本编码中转。
- 首次完整验证成功后保存本机 readiness 记录；同一环境后续启动轻量核对即 ready，不跑 Python／FFmpeg／模型前向，不闪准备页。升级或关键内容变化后仍需完整检查一次。
- 内部命令静默执行，不弹 DOS 窗口，但错误详情、退出码与取消仍可观测；原生文件对话框正常可见。
- 单实例运行，重复启动只聚焦旧窗口；仅最小化时还原，保留最大化状态。
- 窗口按真实工作区与 DPI 适配，降低小屏下的最小尺寸，再定位窗口，避免任务栏、负坐标屏幕和缩放导致越界。
- Job Object 在主进程强退后回收辅助子孙进程。CI 使用独立测试进程强杀验证，不会扫描或结束用户的无关进程。
- 本地 Wails 构建重新生成前端和 PE 资源；无嵌入归档清单但有已安装目录时，也校验并复用已有环境，缺模型不回退到 uv／venv／pip。

## 第一次与重复启动测试

1. Windows 11 ARM 虚拟机先保存干净快照，不为测试提前安装 Python、FFmpeg、PyTorch；x64 电脑也建议使用独立测试用户。
2. 把完整安装器复制到虚拟机本地目录运行，先不从 Mac 共享盘直接运行安装器。
3. 安装后程序目录应有 `runtimes/<本版ID>/`，本地检测不应要求重下依赖或重复解压。模型缺失时显示约 6 MB 的确认按钮，没有点击前不应下载。
4. 确认准备后观察本地校验、模型下载与真实前向，全部通过才进入项目列表。建议至少预留 5 GB，ARM 模拟首次加载可能较慢。
5. 导入短视频，检查播放、分析、人工修正和导出新文件，不覆盖原片或已有成片。
6. 关闭重开两次：同一环境应直接进入软件，不出现准备卡片或内部命令窗口；再次启动只聚焦现有实例，最大化窗口保持最大化。
7. 在 125%／150% 缩放、小屏、左／上任务栏及负坐标副屏下检查窗口位置。自动几何测试不替代实际拖动和切屏交互。

依赖保存在程序目录 `runtimes/<本版ID>/`，模型、成功记录与用户数据位于当前用户配置目录的 `RallyCut`。可在 PowerShell 查看 `Join-Path $env:APPDATA 'RallyCut'`。**不要删除真实项目目录来模拟首启**，优先恢复虚拟机快照；卸载会保留项目数据。

## 异常与路径测试

- 通过原生多选窗口直接选择中文目录与 `\\Mac\Home` 共享视频，测试多选、取消、项目重开、播放与导出。共享服务仍需系统可达，不能从保留 UNC 字符推断网络权限已验证。
- 无模型时断网点击准备，应明确失败、不放行；联网重试可恢复。环境和模型已齐备时，再测断网使用。
- 下载中关闭后重试，不应把残缺文件当成功；准备未完成时菜单和快捷键不能绕过门禁。
- 使用含中文与空格的用户名，保存项目并导出到新的 Unicode 文件名；导出后验证原片不变。
- 任务管理器强制结束应用后检查自有 worker 是否消失；这是有意中断任务，先使用无关紧要的测试项目，不能在重要导出中测试。

## 自动验证与边界

统一 Release workflow 复用 `Windows preview` 的完整链路：预制包构建与搬移、真实模型 CPU 前向、NSIS 安装与卸载保留数据、已安装环境首次准备和重复启动缓存；另外验证无嵌入清单时缺模型仅补模型。Unicode 合成视频会实际导入、保存／重开 JSON、Range 预览、Python／OpenCV 解码与 FFmpeg 导出，并检查原片不变。

发布 EXE 还检查 DPI manifest、图标、版本资源；原生 Job Object 测试验证父进程强杀后子孙进程退出；工作区 API 与多种 DPI 几何、最大化聚焦有回归测试。以本版 workflow 成功记录为准。

**Windows x64 CI 不等于 Windows ARM VM、原生选择窗口点击、`\\Mac\Home` 网络可达或实际多显示器交互已验收。** 本包依赖系统模拟兼容性，不承诺 ARM 下 PyTorch、DirectML 或显卡加速效果；看到加载失败时应区分非法指令、DLL、模型哈希、路径、超时和网络。

## 反馈

展开并复制完整错误详情，提供应用版本、Windows 内部版本号、芯片／虚拟机软件、阶段与操作。先脱敏用户名和绝对路径；不要发送凭据、完整项目或原片。单张进度截图不能代替错误文本。
