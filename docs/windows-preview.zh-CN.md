# Windows 首次环境准备测试版

版本：**v0.1.0-alpha.3-windows.1**。这是 Windows x64 测试版，不是原生 Windows ARM64 版；Windows 11 ARM 将模拟运行 x64 程序。以 Release 中实际构建成功的附件为准。

[打开私有下载页](https://github.com/sundy-li/rallycut/releases/tag/v0.1.0-alpha.3-windows.1)。需要有 `sundy-li/rallycut` 仓库权限；未授权账号可能看到 404。旧 `alpha.2` 保留，网页的默认下载入口暂不切换。

## 下载哪个

- **先选安装器**：`RallyCut-0.1.0-alpha.3-windows.1-windows-amd64-setup.exe`。
- **免安装备用**：`RallyCut-0.1.0-alpha.3-windows.1-windows-amd64.exe`。它同样使用系统 WebView2，不代表不需要运行环境。
- **校验清单**：`SHA256SUMS-windows.txt`。

安装包没有正式发布者签名，Windows 可能显示安全提示。先确认来源和校验值；拿不准时联系维护者，不要关闭系统整体安全保护。

## 第一次测试

1. 在虚拟机中安装并更新 Windows 11 ARM，先保存“干净系统”快照。不要为了测试手动安装 Python、FFmpeg、PyTorch。
2. 将安装包复制到虚拟机本地目录，建议先不要在 Mac 共享盘上直接运行。
3. 安装并打开 RallyCut。缺少 WebView2 时，会先出现中文原生确认提示；取消不会启动。系统已具备时不会再提示。
4. 软件显示环境检测结果。**没有点击“开始准备环境”前，不应自动下载**；环境缺失时不应进入项目列表或剪辑界面。
5. 点击“开始准备环境”，观察 Python、视频工具、分析依赖、模型和自检的阶段进度。首次联网下载可能数百 MB 至数 GB，建议至少预留 5 GB 磁盘空间；下载源必须可达。
6. 全部自检通过后才进入项目列表。导入一段短视频，检查播放、分析、人工修正与导出。
7. 退出、重新打开，完整环境应通过检测，不再重复准备。

依赖保存在当前 Windows 用户配置目录的 `RallyCut` 中，不替换系统 Python，不改全局 PATH；找不到数据目录时可在 PowerShell 查看 `Join-Path $env:APPDATA 'RallyCut'`。不要删除有真实项目的数据目录模拟首次运行，优先恢复虚拟机的干净快照。

## 还要试的异常情况

- 从干净快照开始，断网后点击准备：应提示失败，不放行；联网重试后能恢复。
- 下载中关闭应用，再打开重试：不应将残缺环境当成功。
- 准备未完成时，点击菜单或使用快捷键：不能新建、打开、导入或跳入工作台。
- 路径含空格或中文用户名：正常保存项目、读取本地短视频并导出新文件，不覆盖原片。

## ARM 虚拟机的边界

本包仍是 x64。安装器、Python、视频工具和推理库都受 Windows ARM 的模拟兼容性影响。出现库加载失败或很慢，不应直接推断普通 Windows x64 电脑也会同样失败。建议使用已更新的 Windows 11；不承诺 ARM 模拟下的 PyTorch、DirectML 或显卡加速效果。

GitHub Windows runner 的真实环境准备测试与构建成功，只能证明该 x64 runner 上的相应检查通过，**不等于 Windows ARM 虚拟机、原生安装器交互或真机剪辑已经验收**。虚拟机里先以 CPU 基础流程为准。
