# 算法与实验记录索引

这里面向开发和评估，不是普通用户的使用说明。README 只保留产品用途、实际演示和下载入口。

## 当前实现

球检测使用固定权重的专用模型，整帧分析不以球桌标定成功作为前置门槛。回合由跟踪结果与规则生成；球检测、轨迹筛选、回合切分是不同阶段，不能把轨迹数量或候选数量当成准确率。

- [整帧检测与回归](full-frame-detection.md)：无强制球桌门槛，可选几何和切镜隔离。
- [侧视回合分段](side-transit-segmentation.md)：低位过台与结束确认。
- [观众视角发球分段](spectator-frame-serves.md)：发球准备、自校准尺度与对应回归。
- [手持晃动与切镜](camera-motion-cuts.md)：区分整体平移与真正切镜。
- [对打区域](play-area.md)：场外轨迹的显示过滤，不删除原始检测、不改变分段规则。
- [活动结束确认](activity-end-confirmation.md)、[死球难例](dead-ball-rules.md)：证据、保护边界与反例。

## 本次公开演示的来源和边界

演示是用户指定的樊振东比赛素材短片，不是产品界面截图，也不是重新生成的模型轨迹。使用本机已有项目中保存的真实球轨迹和候选回合，由当前 `backend/export` 真正导出，开启球轨迹与回合编号。只公开精选的 30 秒内片段、GIF 和封面，不上传原片、项目 JSON、标注库或模型。

复现工具：

```bash
go run ./tools/export-demo \
  --project /absolute/path/project.json \
  --output /absolute/path/new-demo.mp4 \
  --rallies 2,9,11 --limit 30
```

工具只读取项目，不修改原视频或项目；导出超过上限会拒绝。源码不内嵌用户文件路径或模型数据。网站版本另作 720p H.264 压缩，GIF 为短预览，均由同一实际导出生成。该演示用于说明产品功能，**不作为整场准确率、独立测试集成绩或模型重新推理的证明**。

用户指定此段作为演示不代表维护者获得赛事完整素材的其他使用权；后续更换素材或扩大分发范围时仍应确认相关权利。不要把原片或未授权的完整成片提交到仓库。
