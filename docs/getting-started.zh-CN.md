# 安装与快速开始

用 RallyCut 做三件事：**找到回合、看清轨迹、导出集锦。**

既可以让机器先分析，也可以自己手动剪；更推荐两者结合：机器找出候选回合，你修正不准确的地方，最后选择合适的覆盖方式导出。

[先看主界面操作](https://rallycut-byc.pages.dev/#workbench) · [再看导出效果](https://rallycut-byc.pages.dev/#demo) · [下载安装包](https://github.com/sundy-li/rallycut/releases/tag/v0.1.0-alpha.2)

## 1. 下载并安装

当前为私有种子测试。先接受维护者的 GitHub 邀请，再登录被邀请的账号下载；没有权限时，下载链接会显示 404。国内访问不便时，可向维护者索取同版本安装包及 SHA-256 校验值；不要把源码下载包当安装包。

- **macOS**：下载 `RallyCut-0.1.0-alpha.2-macos-universal.zip`，解压后将 `RallyCut.app` 拖到“应用程序”。Apple Silicon 是主要测试平台，Intel Mac 仍需进一步实机验证。
- **Windows（实验性）**：有 `-setup.exe` 时使用安装器，否则使用同版本 `-windows-amd64.exe`。Windows 真机体验尚未完成同等验证，需要 WebView2 运行时。

安装包尚未完成正式发布者签名／Apple 公证。确认来源后按系统提示打开；遇到安全提示且拿不准时联系维护者，**不要关闭系统整体安全保护**。版本页面同时提供 SHA-256 校验清单。

## 2. 完成首次准备

**新流程（源码已实现，尚未重新发布安装包）**：打开后先自动检测，缺少环境时点击“开始准备环境”，程序按当前 Windows / macOS 下载 Python、视频工具、分析依赖和模型，并显示阶段进度；全部自检通过才进入项目列表。失败可以重试或重新检测，不会绕过环境准备进入剪辑界面。不改系统 Python 或全局 PATH。首次需联网并预留空间，国内网络还需能访问对应下载源。

**以下仍适用于当前下载的 `v0.1.0-alpha.2`**，请勿把源码的新功能当作旧包已经具备：

当前还不是完全免依赖的安装包：需要本机 **Python 3.10+（推荐 3.12，带 venv）、FFmpeg 和 FFprobe**。不会安装的用户可请维护者协助。

macOS 已安装 Homebrew 的用户可以运行：

```bash
brew install python@3.12 ffmpeg
```

Windows 安装 Python 时勾选加入 PATH，并把 FFmpeg 的 `bin` 目录加入 PATH。重新打开终端，确认以下命令都有版本信息：

```text
python --version
ffmpeg -version
ffprobe -version
```

macOS 的 Python 命令通常是 `python3.12`，而不是 `python`。

第一次打开应用需要联网安装运行环境和下载模型，请等待准备完成。耗时和磁盘占用取决于网络与平台，不能只按安装包大小预估。准备完成后，比赛视频的分析、编辑和导出都在本机进行。

## 3. 从一段短视频开始

1. **新建项目**：输入项目名，导入一段你有权处理的比赛视频。建议先试几分钟的素材。
2. **分析视频**：点击视频标题旁的分析按钮，候选回合会逐步出现在右侧和时间轴上。
3. **回放复核**：点击回合定位，打开“显示球轨迹”检查球的运动。球桌框是独立显示选项，找不到球桌不代表不能分析。
4. **修正边界**：双击回合卡片的起止时间，输入新时间，或取播放器当前时间。右键回合可以标记精彩、无效分、拆分或删除；也可以用 `I`、`O` 手动添加回合。
5. **选择片段**：勾选要导出的回合。片段前后多留多少时间，在顶部齿轮的“设置 → 片段缓冲”中调整。
6. **导出 MP4**：在导出栏按需勾选 **“球轨迹”** 和 **“回合编号”**。如果提示“回合有重叠，怎么导出？”，按下文选择覆盖方式；已人工修正好边界时，通常选“人工回合覆盖分析回合”。编码在“设置 → 导出编码”中选择，首次建议 H.264。
7. **回放成片**：检查回合边界、音画同步和拼接。只勾选一个回合即可单独导出；请使用新的文件名，不覆盖原片或旧输出。

## 4. 人工剪辑与机器分析，怎么结合

### 机器先分析，人工再修正

这是推荐用法。先分析整段素材，再逐个回放机器给出的候选回合：

| 遇到的情况 | 你可以怎么做 |
| --- | --- |
| 开始太早、结束太晚，或把发球剪掉了 | 双击该回合的起止时间，改到你确认的边界。直接修改过的机器回合会被视为人工修正。 |
| 漏掉了一个回合 | 定位到开始处按 `I`，到结束处按 `O`，添加人工回合；也可以点回合列表的加号，再修改起止点。 |
| 把捡球、回送等误当回合 | 取消该回合的勾选、标为无效或删除，避免进入成片。 |
| 一段误包含多个回合，或多个片段需要连起来 | 用右键菜单拆分，或使用相邻合并，再回放检查。 |
| 不想重复看等待、捡球等空档 | 开启“只播回合”复核；这只是回放方式，不等于已经导出。 |

人工剪辑既包括**自己新加的回合**，也包括**人工修正过的机器回合**。重新分析后，人工结果与新的机器候选可以同时存在；是否采用哪一份，在导出时决定。

### 也可以不分析，直接手动剪

导入视频后，直接用 `I`、`O` 标记你要的片段，调整边界、勾选并导出，不必先完成机器分析。回合列表的加号也可以添加片段，添加后记得核对起止时间。

**手动划回合不会自动生成球轨迹。** 若希望预览或导出真实球轨迹，还需要相应素材已有分析产生的轨迹数据；轨迹开关不会凭空补出球的位置。回合编号不依赖球轨迹。

## 5. 导出时，怎么选择覆盖方式

当**已勾选、未标为无效**的人工与分析回合互相重叠，点击导出会出现 **“回合有重叠，怎么导出？”**。选择方式，检查预计回合数和时长，再点击 **“按此方式导出”**。

| 界面选项 | 会怎样处理 | 适合什么情况 |
| --- | --- | --- |
| **人工回合覆盖分析回合** | 保留人工添加或修正的回合；与之重叠的分析回合整段不导出。其他不重叠、已勾选且未标为无效的分析回合仍保留。 | 你已经修正好边界，希望以人工结果为准。 |
| **分析回合覆盖人工回合** | 保留分析回合；与之重叠的人工回合整段不导出。 | 想优先采用机器结果，暂不使用重叠的人工版本。 |
| **合并区间，不重叠** | 将重叠区间合成一段连续画面，保留覆盖到的所有画面，不重复播放。 | 不想漏画面，愿意保留更长的片段。这也是未设置过策略时的默认方式。 |
| **按先后顺序覆盖** | 先开始的回合保留；与它重叠、后开始的另一来源回合整段不导出。 | 希望按开始时间决定采用哪份，而不是固定人工或分析优先。 |

**注意：这里的“覆盖”是整条回合的取舍，不是只替换相交的那几秒。**

例如，机器回合是 `00:10–00:20`，你手动添加的是 `00:12–00:18`，两者都勾选且未标为无效。假设前后保留时间都为 0，且没有其他回合：

- 选 **人工回合覆盖分析回合**：导出 `00:12–00:18`。机器的整条 `00:10–00:20` 被跳过，**不会另外补回 `00:10–00:12` 和 `00:18–00:20`**。
- 选 **分析回合覆盖人工回合**：导出 `00:10–00:20`。
- 选 **合并区间，不重叠**：导出一段 `00:10–00:20`，不会把重叠画面放两遍。
- 选 **按先后顺序覆盖**：机器回合先开始，所以这个例子导出 `00:10–00:20`；不是始终偏向机器。

这些方式只决定导出采用的回合，**不会删除原回合、改动项目时间轴、覆盖原视频或覆盖已有成片**。人工与人工、分析与分析之间的重叠会自动合并，不使用上面的跨来源取舍规则。未勾选或已标为无效的回合不参与导出，也不参与覆盖。

前后保留时间会进一步影响实际成片边界；如果你想严格按人工标记的起止点剪，先在“设置 → 片段缓冲”检查这两个值。导出后仍需回放，确认没有因覆盖方式漏掉想保留的内容。

## 6. 编辑时常用的操作

| 操作 | 怎么做 |
| --- | --- |
| 播放／暂停 | 空格或 `K` |
| 添加一个回合 | `I` 标记开始，`O` 标记结束 |
| 修改回合起止点 | 双击回合卡片上的时间 |
| 撤销／重做 | macOS：`⌘Z`／`⇧⌘Z`；Windows：`Ctrl+Z`／`Ctrl+Y` |
| 设置 | 顶部齿轮，或 `⌘,`／`Ctrl+,` |
| 全部快捷键 | 顶部键盘按钮，或 `⌘/`／`Ctrl+/` |

编辑自动保存。撤销历史只在当前会话中保留；切换项目、切换素材或分析完成后会清空，不能代替项目备份。导出设置、项目改名和素材增删不在撤销范围内。

## 7. 重新分析与项目备份

重新分析会替换未经人工修改的机器回合，保留人工添加和人工修正的回合；与人工重叠的新分析候选也会保留，方便在导出时选择。回合列表可能同时出现两个来源，这是正常的，不代表导出一定会重复。

直接删除的机器回合没有永久排除记录，重跑后可能再次出现。如果只是暂时不想导出，优先取消勾选；与旧候选匹配上的新机器回合会延续取消选择状态，但候选变化较大时仍应重新复核。

重新分析完成会清空当前撤销历史。重要项目请先“另存为”，不要把撤销当成分析前快照。

项目文件不包含原视频。不要移动、改名或替换它引用的原片；换电脑只复制项目 JSON 并不能带走视频。升级和大幅编辑前，先“另存为”保留项目副本。

自动识别可能漏回合或误把回送、捡球当成回合。最终保留哪些片段，由你复核决定。
