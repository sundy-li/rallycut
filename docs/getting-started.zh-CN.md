# 安装与快速开始

用 RallyCut 做三件事：**找到回合、看清轨迹、导出集锦。**

[先看演示](https://rallycut-byc.pages.dev/#demo) · [下载安装包](https://github.com/sundy-li/rallycut/releases/tag/v0.1.0-alpha.2)

## 1. 下载并安装

当前为私有种子测试。先接受维护者的 GitHub 邀请，再登录被邀请的账号下载；没有权限时，下载链接会显示 404。

- **macOS**：下载 `RallyCut-0.1.0-alpha.2-macos-universal.zip`，解压后将 `RallyCut.app` 拖到“应用程序”。Apple Silicon 是主要测试平台，Intel Mac 仍需进一步实机验证。
- **Windows（实验性）**：有 `-setup.exe` 时使用安装器，否则使用同版本 `-windows-amd64.exe`。Windows 真机体验尚未完成同等验证，需要 WebView2 运行时。

安装包尚未完成正式发布者签名／Apple 公证。确认来源后按系统提示打开；遇到安全提示且拿不准时联系维护者，**不要关闭系统整体安全保护**。版本页面同时提供 SHA-256 校验清单。

## 2. 完成首次准备

当前还不是完全免依赖的安装包：需要本机 **Python 3.10+（推荐 3.12，带 venv）、FFmpeg 和 FFprobe**。不会安装的用户可请维护者协助。

macOS 已安装 Homebrew 的用户可以运行：

```bash
brew install python@3.12 ffmpeg
```

Windows 安装 Python 时勾选加入 PATH，并把 FFmpeg 的 `bin` 目录加入 PATH。重新打开终端，确认以下命令都有版本信息：

```text
python --version
ffmpeg -version
ffprobe -version
```

macOS 的 Python 命令通常是 `python3.12`，而不是 `python`。

第一次打开应用需要联网安装运行环境和下载模型，请等待准备完成。耗时和磁盘占用取决于网络与平台，不能只按安装包大小预估。准备完成后，比赛视频的分析、编辑和导出都在本机进行。

## 3. 从一段短视频开始

1. **新建项目**：输入项目名，导入一段你有权处理的比赛视频。建议先试几分钟的素材。
2. **分析视频**：点击视频标题旁的分析按钮，候选回合会逐步出现在右侧和时间轴上。
3. **回放复核**：点击回合定位，打开“显示球轨迹”检查球的运动。球桌框是独立显示选项，找不到球桌不代表不能分析。
4. **修正边界**：双击回合卡片的起止时间，输入新时间，或取播放器当前时间。右键回合可以标记精彩、无效分、拆分或删除；也可以用 `I`、`O` 手动添加回合。
5. **选择片段**：勾选要导出的回合。片段前后多留多少时间，在顶部齿轮的“设置 → 片段缓冲”中调整。
6. **导出 MP4**：在导出栏勾选 **“球轨迹”** 和 **“回合编号”**，把橙色轨迹和左上角编号一起放进成片。编码在“设置 → 导出编码”中选择，首次建议 H.264。
7. **回放成片**：检查回合边界、音画同步和拼接。只勾选一个回合即可单独导出；请使用新的文件名，不覆盖原片或旧输出。

## 4. 编辑时常用的操作

| 操作 | 怎么做 |
| --- | --- |
| 播放／暂停 | 空格或 `K` |
| 添加一个回合 | `I` 标记开始，`O` 标记结束 |
| 修改回合起止点 | 双击回合卡片上的时间 |
| 撤销／重做 | macOS：`⌘Z`／`⇧⌘Z`；Windows：`Ctrl+Z`／`Ctrl+Y` |
| 设置 | 顶部齿轮，或 `⌘,`／`Ctrl+,` |
| 全部快捷键 | 顶部键盘按钮，或 `⌘/`／`Ctrl+/` |

编辑自动保存。撤销历史只在当前会话中保留；切换项目、切换素材或分析完成后会清空，不能代替项目备份。导出设置、项目改名和素材增删不在撤销范围内。

## 5. 重新分析与项目备份

重新分析会替换未经人工修改的机器回合，保留人工添加和人工修正的回合。两种来源可能重叠；导出时可以选择人工优先、分析优先、合并或按先后处理，**不会因此改掉项目里的时间轴**。被人工删除的机器回合，重跑后可能再次出现。

项目文件不包含原视频。不要移动、改名或替换它引用的原片；换电脑只复制项目 JSON 并不能带走视频。升级和大幅编辑前，先“另存为”保留项目副本。

自动识别可能漏回合或误把回送、捡球当成回合。最终保留哪些片段，由你复核决定。
