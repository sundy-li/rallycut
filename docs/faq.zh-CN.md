# 常见问题与反馈

## 下载链接为什么显示 404？

当前是私有种子测试。先接受维护者的 GitHub 仓库邀请，再登录被邀请的账号。下载页公开，但 GitHub 安装包不支持匿名下载。不要把 404 当成文件一定不存在。

## 第一次打开为什么还要下载东西？

安装包不包含完整的 Python 运行环境和模型。首次打开会准备应用自己的环境并下载依赖，耗时取决于网络和平台，不保证几分钟完成。完成后，比赛视频的分析、编辑和导出都在本机进行，不需要上传比赛视频。

## 找不到 Python、FFmpeg 或 FFprobe 怎么办？

需要 Python 3.10+（推荐 3.12，带 venv）以及 FFmpeg／FFprobe。参考[安装指南](getting-started.zh-CN.md)，不会配置时请维护者协助。Windows 修改 PATH 后要重新打开应用。

## 系统提示未知开发者或未知发布者？

种子包尚未完成正式发布者签名／Apple 公证。请核对来源和校验值，按系统提示处理；不确定时联系维护者。不要关闭 Gatekeeper、SmartScreen 或杀毒软件。

## 为什么预览有轨迹，导出却没有？

预览开关和导出选项相互独立。在**导出栏的“导出叠加”**中勾选“球轨迹”；需要左上角编号时，再勾选“回合编号”。设置保存在当前项目里。场外轨迹不会绘制，原片里没有识别到球的时段也不会凭空补轨迹。

## 回合编号导出提示缺少字体？

编号需要本机可用的中文字体。先关闭“回合编号”完成导出，再联系维护者检查字体；这不影响回合剪辑或球轨迹选项。不要安装来源不明的字体包。

## 分错回合或漏回合怎么办？

点击回合回放，双击起止时间修正，或用 `I`、`O` 手动补一个回合。右键可删除误识别、标记无效分或精彩片段。遮挡、慢动作和机位变化都可能影响结果，自动识别不能替代复核。

## 重新分析会丢掉我的编辑吗？

人工添加与修正的回合会保留，未经人工修改的机器回合会替换。两者重叠时，会在导出前让你选择优先级，不会直接改掉项目时间轴。人工删除的机器回合可能在重跑后回来；重要项目仍建议先另存备份。

## 如何撤销？

macOS 用 `⌘Z`，Windows 用 `Ctrl+Z`，也可以点顶部撤销按钮。支持回合编辑、勾选和剪辑规则等操作。撤销历史不跨会话保留，切换项目／素材、分析完成后会清空；导出设置、项目名和素材增删不在撤销范围内。

## 预览黑屏或导出失败？

预览先点“重试预览”，记录完整错误文本。部分原片编码不被系统播放器支持，可把原片另存成兼容的 H.264 MP4，再作为新素材导入，别覆盖原片。

导出时使用新的 `.mp4` 文件名，确认剩余空间、目录权限和 FFmpeg。硬件编码不可用时会尝试软件编码，可能更慢；失败后不要把未完成文件当正式成片。

## 换电脑后为什么找不到视频？

项目只保存原视频的位置，不包含视频文件。移动、改名或替换原片后可能失效，目前不能自动重新定位。请保留原路径，或重新导入并保留旧项目副本。

## 怎么反馈？

直接回复邀请你的维护者，说明：

```text
应用版本、操作系统与芯片：
操作步骤：
期望结果与实际结果：
完整错误文本：
原片时间范围（例如 00:12:30–00:12:42）：
```

日志和项目可能包含用户名、素材名称、绝对路径等信息，发送前检查并脱敏。不要默认发送整场视频、完整项目、密码或访问令牌；确需提供短片时先确认版权、肖像权和接收范围。
