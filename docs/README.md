# RallyCut 使用指南

**机器先找回合，人工把关修正，最后导出你的乒乓球集锦。**

RallyCut 支持三种用法：让机器分析回合、自己手动剪辑，或把两者结合。机器哪里剪得不对，就手动调整起止点、补上漏掉的回合；导出时再选择采用哪一份。

**推荐流程：导入比赛 → 机器分析 → 回放并人工修正 → 选择覆盖方式 → 导出集锦。**

如果只想自己剪，也可以导入视频后直接标记回合，不必先运行分析。

## 剪得不对，人工来补

点击回合回放，双击起止时间修改边界；漏掉的片段可以按 `I` 标记开始、`O` 标记结束，手动加进列表。人工添加或修正过的回合，重新分析时会保留。

导出遇到人工与机器回合重叠时，选择 **“人工回合覆盖分析回合”**，以人工结果为准；其余不重叠、已勾选且未标为无效的机器回合仍会导出。还可以选择分析优先、合并区间或按先后顺序覆盖。

**覆盖发生在导出时，不会改掉项目时间轴；被覆盖的回合整段不导出，不是只裁掉相交的几秒。** 具体例子见[快速开始](getting-started.zh-CN.md)。

视频在本机处理，不需要上传。自动识别仍需回放复核；首次准备需要联网并明确确认：Windows 完整安装器已含依赖、只需补缺失模型，macOS 自动准备私有环境；不用手动安装 Python／FFmpeg。手动剪辑不会自动生成球轨迹。当前 GitHub 下载需要仓库权限；国内访问不便时，可向维护者索取同版本安装包与校验值。
