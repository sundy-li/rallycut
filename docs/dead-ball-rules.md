> 术语：这里的“分”（point）指**一次发球到该分结束**（出界、下网、落地、对方未接到），包括发球自杀与接发失误；不是“球来回一趟”的 exchange。界面统一显示“第 N 分”，内部字段 `rallies` 仅为兼容保留。

# 死球与重新发球：0043 两个真实错例

## 问题不是“球消失得够不够久”

球被接住、拾起、回送给发球方时仍会产生轨迹。原来的 1.15 秒轨迹间隔 + 音频分组会将不同回合串起来；只减小间隔又会切坏遮挡和正常对拉。

新增 `dead-ball-v1`：`IN_PLAY → 待确认结束 → WAIT_SERVE → 新发球/有效对拉 → IN_PLAY`。球检测权重不变，规则仍属实验，不是训练过的裁判/动作模型。

## 当前证据

- 发球即回合：每个死球区间的第一段轨迹按 ≥0.35s 保留；结束于任何死球事件的短回合（发球自杀、接发失误）也保留。是否删除由用户在时间轴决定，系统不按得分高低丢弃。
- `fragment_bridge`：同一回合内检测断档 ≤0.75s、且中间没有死球证据或切镜头时合并为一段（保留 `bridged=true` 供排查）；死球与切镜头永远不桥接。
- `out_without_table_bounce`：侧拍中球越过球桌中线，未见可能落台，随后在桌面上方连续越过接球端端线；等待短观察期确认。
- `below_table_stopped`：真实下降轨迹进入桌面以下，持续低位且明显减速/停滞，无快速救球恢复。针对 34 秒案例；不把每一次低位防守直接判死。
- `held_after_flight`：先有快速来球，运动员端区域内持续低运动；随后重新运动会取消待确认边界。
- `net_drop_same_side`：必须有可信网面几何，同时观察到同侧下坠、水平停滞/回落，且没有继续穿过。擦网后继续有效过网不能结束。
- 自动主球桌/网面几何不足时不猜：桌面 bbox 中点不是球网。透视机位暂不启用基于左右端线的强判定。

下一回合恢复需要**朝网运动的己方半台落球/发球证据**；如果落点遮挡，可由后续往返有效对拉恢复，标明较弱依据。单次跨台回送球不能冒充重新发球。

所有自动原因均以“疑似/候选”展示，分数是规则证据强度，不是校准概率。

## 与后续流程的约束

1. 记录死球到再次发球之间的区间，视觉、音频分别在有效区间内重新组合；音频不能跨越死球区间。
2. 流式候选也使用同一规则。临时输出不能把当前未结束的 `WAIT_SERVE` 当最终结果，也不能重新合并已确认边界。
3. `boundary_before: true` 标记恢复后的第一段；`end_reason/end_event_time/end_confidence` 标记前段终止依据。
4. 识别边界和剪辑缓冲是两回事。导出仍保留 pre/post-roll；若跨越受保护的下一回合，则在两回合间空闲区间中点分配缓冲，两段保持独立，不重复、不重新合并。未勾选的邻居也提供分界，避免选择变化绕过保护。若某个已勾选、未作废回合的自身内容（不含缓冲）已越过下一回合的保护起点（例如人工标记与机器候选重叠），视为用户覆盖：两段合并为一段连续导出，不重复画面，也不再报错拒绝导出。
5. 显式手动合并可覆盖中间自动边界；手改起止解除该侧旧自动证据，原始分析记录不删除。重新分析不覆盖非空人工时间轴；空时间轴（包括人工删空）自动采用机器候选，非空人工时间轴采用新候选需确认。
6. 候选起点使用 1.6 秒发球前导，但不得越过上一候选或死球边界；这是早期球观测缺失时的边界补偿，不等于识别到了真实发球动作。候选结束裁到最后一个活跃飞行，持续至少 0.8 秒的低速 / 台下拾球尾及其后的回送球不并回；无可信台面时只按速度，不按台下位置裁剪。
7. 缓存键已有 worker 源码 digest，此规则/网面代码已纳入；旧成功缓存不会冒充新规则结果。

分段按二分索引分桶，每个观测只分配一次，避免长视频流式更新每次对全部历史区间重复扫描全部轨迹。

## CLI / skill

默认启用 `dead-ball-v1` 规则；不再保留 legacy 切分开关。

有经用户确认的网面投影时可传 `--net-region LX LT LB RX RT RB`（归一化坐标，两端上/下边界）。没有证据不要猜坐标，也不要将台面中点作为网。默认先尝试多帧双网柱一致性标定，失败则禁用网面分支，不阻止其他强结束证据。

JSON 增加：

- `summary.rally_state_version`
- `summary.rally_events[]`：`type/time/confirmed_at/reason/confidence/x/y/signals`。`confirmed_at` 与回溯边界 `time` 分开。
- `summary.net_region/net_region_source`
- `segments[].end_reason/end_event_time/end_confidence/boundary_before/start_reason`

这些信息随独立 skill、Go 协议、项目保存、人工编辑和导出保留。无证据时字段缺省，不编造事件。
