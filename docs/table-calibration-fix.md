# 蓝色桌端机位校准失败修复

> 历史实现与证据。当前默认已迁移为[无需前置标定的整帧检测](full-frame-detection.md)，下列搜索只在 `--table-mode precalibrate` 显式启用时使用，不再是分析门槛。

## 实际故障

素材 `DJI_20261020201410_0044_D.MP4`（1080p / 29.97 fps，约 25 分钟）在开头报：

> 未自动定位球桌；不对未知邻桌进行自动回合分段

旧代码仅在正式推理开头寻找偏紫色、宽高比大于 3.5 的单帧连通区域，超过 10 秒就退出。该素材是蓝色桌面、桌端透视、蓝色地板，且开头有人靠近镜头；与原验证素材的紫色侧拍机位不同。旧函数在 0 / 3 / 8 / 15 / 30 秒返回空，第 60 秒却选中右后方区域，因此不能简单扩展颜色范围或延长等待。

## 修复

新增共享模块 `vision/table_locator.py`：

1. 原紫色侧拍路径增加桌沿亮线支撑，拒绝窄小的后方颜色区域。
2. 蓝色透视路径结合相交前桌沿、桌面蓝/紫颜色、大小 / 位置 / 凸四边形约束，而不是仅对蓝色取连通域。
3. 默认先搜索开头 **600 视频秒**：前 30 秒每秒一帧，之后每 5 秒一帧，使用至少三个不同采样时刻的一致候选，稳定后提前结束。仍失败时会[分层跳搜后段](table-jump-search.md)，每个局部窗口独立确认，额外默认最多 96 次新采样。相近强度的独立多桌候选存在歧义时拒绝自动选择。
4. 选定近似主桌 ROI 后重新打开原片，从 0 秒开始正式推理，保留解码 PTS，不丢弃预校准期间的画面。
5. 无稳定证据时仍报错，不退回整幅画面，不生成占位回合。预校准结果不代表精确桌角或通用球桌检测模型。

模块同时加入 Go 内嵌 worker 和 portable skill 资源清单；源码摘要自动让旧分析缓存失效，权重不变。分析摘要附带校准方法、支撑采样数和最后支撑时间戳。

## 600 秒搜索与耗时

在同一失败原片 / 本机上，强制遍历计划（不早停）的测量：

| 模式 | 检查帧数 | 耗时 |
|---|---:|---:|
| 原顺序解码前 30 秒 | 30 | 4.518 秒 |
| seek 抽样前 30 秒 | 31 | 2.551 秒 |
| seek 抽样前 600 秒 | 145 | 11.657 秒 |

生产逻辑一旦稳定就提前结束，不会每次都扫完 600 秒。`CAP_PROP_POS_MSEC` seek 不支持、位置误差过大或 PTS 不递增时，丢弃该次观察并重新顺序解码校准；此路径可能更慢。读出的实际 PTS 仍用来做多帧一致性判断，不能用请求位置伪造观测时间。相似强度多桌仍拒绝自动选择。

skill CLI 暴露 `--calibration-seconds 600`（初始窗口，大于 0，最多 3600）；桌面默认 600，后段额外跳搜预算默认 96，可用 `--calibration-jump-samples 0..384` 调整/关闭。短于窗口的素材只检查其自身时长。摘要另记录搜索窗口、实际抽样帧数、耗时和 `seek_sparse` / `sequential_fallback` 策略。CPU、存储和 GOP 长度都会影响速度，11.657 秒不是统一性能保证。

## 已验证范围

- 失败原片：约 8 秒得到 `(319, 214, 706, 298)` ROI，归一化基准为 960×540，覆盖前景主桌，排除右后方区域；4 个支撑时刻。
- 旧紫色侧拍原片：多帧校准仍得到原主桌，未扩大到全画面。
- 失败素材前 30 秒：stream copy 抽样，不改变视频像素，通过正式 Go → Python / MPS 分析，解码 900 帧、12 条保留短轨迹、2 个回合候选。输出 `/tmp/rallycut-table-fix/fixed-analysis.json` 和 `fixed-first30.rallycut.json`。
- 校准测试覆盖蓝地板 / 围挡负例、绿色非目标桌面、透视主桌、旧侧拍、首帧遮挡 / 邻桌偶发误命中、多桌歧义、短素材、正式推理从第 0 帧重新开始；另外覆盖 145 帧计划、30 秒后才出现球桌、遍历到 600 秒失败、seek 不支持 / 不可靠后的安全回退。真实素材回归通过显式 `RALLYCUT_TEST_TABLE_VIDEO` 启用。

**本次没有重跑完整 25 分钟，也没有新增回合准确率验收。** 遮挡、白边不清、复杂多桌和移动机位仍可能失败。先重启新版并重新分析原项目，不要把 30 秒验证等同于整场识别保证。

## 复验

```bash
RALLYCUT_TEST_TABLE_VIDEO=/absolute/DJI_20261020201410_0044_D.MP4 \
  .venv/bin/python -m unittest discover -s vision/tests -p test_table_locator.py -v
just build
just skill
```

独立版用 `just run`；`just dev` 使用者需重启以释放新版内嵌 worker。skill 更新后按新的运行时摘要准备环境。
